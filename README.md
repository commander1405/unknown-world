# UNKNOWN WORLD

Open-world 2D adventure / exploration game for the browser.

**Play:** https://commander1405.github.io/unknown-world/

## Features

- Top-down smooth Canvas 2D world (no external asset packs)
- Hybrid map: hand-placed village, cave, lake, mountains + procedural forests
- Resource gathering, inventory, quests, XP / leveling
- Day / night cycle, collision, camera follow
- LocalStorage save / continue / new game
- Desktop (WASD, E, I, ESC) and mobile virtual joystick

## Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move | WASD / Arrows | Joystick |
| Interact / Gather | E | E button |
| Inventory | I | I button |
| Pause | ESC | Pause via… use ESC on desktop |

## Run locally

Open `index.html` via any static server, e.g.:

```bash
npx serve .
```

## Tech

Vanilla HTML / CSS / JavaScript modules. No build step. GitHub Pages from `main` root.
